## Test Strategy

The flow is tested through its public contract in `tests/it_doctask_flow.rs` against a real temporary library: `Engine::init` on a temporary directory, files written with `std::fs` and recorded with `Engine::capture`, the schema applied by `DocFlow::open`. Baselines and tasks are created through `DocTaskService` (WP06) so that the rows are the ones the application writes. Each test asserts on returned values, on the rows read back through `DocStore` (`tasks`, `plans`, `approvals`, `evidence`, `links`, `dependency_edges`), on the chain read through `DocStore::events` (kinds, `from_status`, `to_status`, actor and actor kind, in `seq` order), and on the error codes compared as whole `DocError` values.

Two fixtures reach states that no public operation produces yet. A test writes the state through a second connection (the `count()` pattern of `tests/it_doctask_service.rs`): an anchor is set to `relocated` in `doc_anchors`, or a task status is changed with `Store::set_task_status` (the bypass that `STATUS_DRIFT` detects). An edit component is a small fake `EditPlanSupport` in the test file: it returns the expected version of the target and the hashes it is given, so that the stale path (guard 4) can be reached by editing and capturing the target file after submission.

After every legal path the test asserts that `verify()` reports no error-level finding (TC-880, TC-890, TC-894, TC-899). Verification of the tests runs in the CI job `release.yml` (`cargo test --locked --all-targets` on `windows-latest`). Pure helpers of the module are tested in its `tests` module (TC-899).

## Boundary & Failure Cases

- Ten proposals is the boundary of the quota (TC-898, ninth call succeeds, eleventh refused); forty events is the boundary of the rate window (TC-898, thirty-ninth change succeeds).
- Title, reason, summary and label lengths: exactly at the limit is accepted and one more is refused (TC-896 label, TC-883 empty reason).
- Handles: `T-n`, a bare number, a full UUID and a hexadecimal prefix resolve; an ambiguous prefix returns `E_AMBIGUOUS` (TC-886 agent view and TC-895).
- Compare-and-set and row write failures roll back the whole step (TC-882).
- A stale edit plan is detected before any write other than the T11 commit (TC-891).
- A cycle is detected before the dependency row is written (TC-895).

## Regression Scope

- `tests/it_doctask_store.rs` and `tests/it_doctask_service.rs` (WP05, WP06) must pass unchanged; the store's `RowWrite` enum gains two variants, which the existing matches cover through the store's own validation.
- `tests/it_doctask_migration.rs` (IT-050) is the source of the legacy fixture of TC-899.
- `tests/it_nema_task.rs` (IT-005) is unaffected.
