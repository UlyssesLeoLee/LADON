Source: `src/doctask_mcp.rs`

## Test Strategy

Three levels cover the module. Unit tests live in the `tests` module of `src/doctask_mcp.rs`; they use no database and cover the descriptors, the argument rules, the envelopes, the transition plan, the panic guard and the serve checks. Store-backed behaviour (disclosure rows, read-only invariant, gate, quota, duplicate creation, global rule file in the MCP process) runs through the real binary in `tests/it_mcp_stdio.rs` with the stub client in `tests/support/mcp_stub.rs`. The cross-process case is in `tests/it_doctask_concurrency.rs`, and the token scan that keeps human-only operations out of the module is in `tests/it_arch_guard.rs`.

The unit function `ut_157_tool_list_and_panic_guard` calls the case functions `tc950_tool_list_snapshot`, `tc951_catch_panic_reports_internal_and_continues` and `tc952_panic_hook_writes_location_only`. The other unit cases are the functions named in the table. Panic tests serialize on a test-local mutex and restore the previous hook before they return. Expected JSON is compared as parsed `serde_json::Value`, except for the envelope key checks.

## Boundary & Failure Cases

- Limits: 200 and 6000 characters for `max_chars`; 4000 for `description` and for the work summary; 1000 for the combined evidence text; 50 for list limits; 2000 candidate files and 1 MiB per scanned file in `doc_mentions_find`; 32 KiB for any result text.
- A line feed inside `text` passes validation and is escaped by the envelope, so framing holds.
- A list cut by `fit_list` keeps whole items only, so no multi-byte character is split.
- An unreadable global rule file makes every file-bearing call return `E_POLICY_DENIED`, while `initialize` and `tools/list` still answer.
- A version refused by the gate and a missing version produce the same `E_NOT_FOUND` text.
- A binary or non-UTF-8 file read as text produces `E_UNSUPPORTED_FILE`.
- A panic during a call answers that call with `E_INTERNAL` and leaves the next call working.

## Regression Scope

- TC-940 to TC-949 in `src/mcp.rs` (the protocol layer) must keep passing. The host answers only through `ToolCall` and `Option<Value>`, and unknown names still produce -32602.
- A change to a tool name, a required property, a length bound or the `readOnlyHint` set must fail TC-950 or TC-958 before any caller changes.
- A change to the envelope keys must fail TC-954 and the shape checks of TC-958.
- The stdout rule (one JSON object per line, no print macros) is enforced by TC-958 and by the token scan in TC-959. The module-level `deny` attributes are checked only when clippy runs (design 57 section 15.1).
