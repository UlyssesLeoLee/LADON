## Test Strategy

Unit tests live in the `#[cfg(test)]` modules `refresh_tests` and `tests` at the end of `ui-prototype/src/model.rs`. They are pure: inputs are built in memory and outputs are compared with values written out in full. No temporary file, database or Slint object is used. Times are formatted only with explicit `FixedOffset` values, and diff timing uses explicit `Duration` values, so the results do not depend on the machine's time zone. The two-second timeouts are far above the time that the small inputs need, and the zero timeout is always exceeded. The model lane `cargo test --lib --no-default-features` runs all cases.

Requirement coverage: REQ-009 (binary detection TC-602; version rows, sections and diff TC-610, TC-613 to TC-615); NFR-013 (path checks TC-603 to TC-608); NFR-004 (sensitive status and availability text TC-612, TC-613); NFR-007 (actor and reason in every version row, TC-613); NFR-002 (truncation and approximation flags TC-614, TC-615); NFR-015 (Chinese status, availability and section texts TC-610, TC-612, TC-613); NFR-003 (every function is pure and offline).

## Boundary & Failure Cases

- The binary check looks at every byte: a zero byte at index 8000 of an 8001-byte slice, and at index 8999 of a 9000-byte slice, makes the content binary (TC-602).
- Path checks stop at the first failing component. `.git/..` gives `Internal` and `../.git` gives `Traversal` (TC-605).
- A component that starts with a dot is accepted unless it equals `.ladon` or `.git` after trailing dots and spaces are removed, so `.gitignore` is accepted (TC-603).
- Device names are matched on the part before the first dot, with trailing spaces removed. `CONSOLE`, `COM10` and `COM10 .txt` are accepted; `con.txt`, `Com1`, `CON .txt` and `aux . x` are refused (TC-603, TC-606).
- A deleted ledger row never marks a file as tracked (TC-612).
- A link or a directory with a ledger row is never tracked (TC-612).
- An RFC 3339 input that does not parse is returned unchanged, and a missing or out-of-range timestamp shows `—` (TC-609).
- The size unit is the first unit whose one-decimal value is below 1024.0, so `1048575` shows `1.0 MB` (TC-601).
- A version with a negative byte size shows `—` and keeps all other fields (TC-613).
- A section list that contains an engine marker shows the Chinese message for that marker, not the marker key, and no key list. The deferred-content marker takes precedence over the large-content marker (TC-610).
- A diff limit of zero or one still reports the full totals (TC-615).
- Gap lines count toward the line limit, so a limit can end a diff on a Gap line (TC-615).
- A zero timeout marks the diff as approximate; the lines are still produced from the inputs (TC-615).
- A lone CR ends a line token and stays in the text of that line (TC-614).
- Identical and empty inputs produce no lines and no Gap (TC-614).
- An empty selected path never matches a row, so a refresh made with no selection keeps none (TC-617).
- `listing_changed` compares all fields and the order of the rows, so a row whose status changes is a change even when its name stays the same (TC-618).
- `drive_rows` skips every entry whose character is not an ASCII letter, and a letter that repeats in either case keeps only its first entry (TC-619).
- `drive_rows` sorts its rows by letter, not by input order (TC-619).

## Regression Scope

`app.rs` calls `validate_relative` and `check_component` for relative paths and for the components of root candidates, `same_directory` for the profile-directory check, `strip_extended_prefix` for display paths, `browse_rows` for `ListFolder`, `version_rows` for `LoadHistory`, `diff_lines` for `LoadDiff`, and `drive_rows` for `ListDrives`. `is_binary` has no caller in `app.rs`, which checks for a zero byte inline in `LoadDiff`. Drive roots are accepted as workspace roots, so `is_drive_root` does not refuse root candidates; only the user profile directory is refused. The window shows the status text of each drive row from `drive_status_text`. The outputs of these functions are part of the replies of those commands. The kernel lane in `tests/it_slice_a.rs` (TC-620 to TC-645) depends on the same outputs and runs under `cargo test --no-default-features --features kernel`.
