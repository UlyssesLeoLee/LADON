# 14. 基线验收与范围外声明

## 1. 必须成立的业务结论
1. 每份纳管文档拥有稳定 FileRef 和从基线起完整的已捕获版本事件。
2. 版本历史可以按时间、操作者、关联要件、任务及云端位置展开。
3. `.LADONignore` 文件/按钮可保护内容和历史详情，默认阻止外传。
4. 普通文件管理不等待 Agent、数据库云同步或 Google Drive。
5. 没有可验证历史副本时任何自动空间回收禁止删除原内容。
6. 无冲突 FileSpace 可并行执行，发生同一文件冲突时要求重新确认。
7. 变更需求无需重新读取项目所有要件，仅增量筛选。

## 2. 测试范围
UT 验证算法与边界；IT 验证模块契约/数据库/压缩加密/恢复/授权拒绝；ST 在 Windows 11、外接卷、NAS（如有）、Google Drive 实账号及模型后端进行验收。UAT 由用户自己签字。任何未执行测试只显示 `Not Run`。

## 3. 退出条件
P0 全部 `Implemented + Tested`、无严重未解决缺陷、回滚预案可执行、安全/历史完整性及同步隔离通过 ST；P1/P2 可以后续里程碑，但不得在 1.0 宣传为现成功能。
