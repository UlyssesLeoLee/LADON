# 13. 用例清单和业务流程

| UC | 触发者 | 前置条件 | 主流程 | 异常/替代 | 结果 |
|---|---|---|---|---|---|
| UC-01 | 用户 | 目录存在 | 初始化→写 `.LADONignore` →建 Turso →扫描 | 无权限→拒绝 | FileRef/基线建立 |
| UC-02 | 文件监听 | 文件稳定保存 | Hash→结构 Diff→版本→事件 | 未变化→跳过；读取中变化→重试 | 增量版本 |
| UC-03 | 用户 | 文件纳管 | 右键查看历史→查询版本目录→按需 Diff | 冷对象缺失→说明来源不可用 | 真实历史显示 |
| UC-04 | 用户 | 有可恢复版本 | 查看计划→批准→校验当前 Hash→恢复→生成新版本 | 当前文件已改→拒绝覆盖 | 恢复已审计 |
| UC-05 | 用户 | 已配置 Ignore | 右键排除→规则落盘→执行策略 | 规则语法错→外传拒绝 | 敏感边界生效 |
| UC-06 | 用户 | 选择文件夹 | 预设标签/描述→分析→标签落库 | 远端 AI 与敏感冲突→跳过 | 可检索标签 |
| UC-07 | 开发 Agent | 既有批准要件 | Prompt Hook→相关条款筛选→冲突建议 | 要件缺失→人工指定 | Concept CR |
| UC-08 | Agent | FileSpace 作用域 | 取增量 Snapshot→分析→拟定计划→人审→提交 | 版本冲突→重取快照 | 可追溯任务 |
| UC-09 | 用户 | 非敏感版本 | 选择 Google Drive→归档→读回/解密/Hash→可驱逐 | 上传或校验失败→留本地 | 冷历史可恢复 |
| UC-10 | 管理员 | 存储提供商变化 | 新 Adapter→复制→校验→切换→旧端清理计划 | 中途失败→继续从旧端读取 | 完整迁移 |
| UC-11 | 用户 | 目录内文档条款 | 选段落→添加内联注释→绑定任务→通知 Agent | 条款版本变更→提示迁移 | 文档即任务 |
| UC-12 | 系统 | Git Worktree 长期闲置 | 检查工作区→归档未提交/未跟踪→验证→回收 | 任一必要数据无法上云→禁止清理 | 回收安全 |

## 业务状态及边界
历史对象状态：`local_only → queued → uploading → remote_written → verified → local_evictable`；失败进入 `retry_wait` 或 `quarantined`。对于敏感数据固定为 `local_only_protected`。

## 异常优先级
E1 数据泄露/不可恢复/无声历史丢失（阻断）；E2 Agent 无审批覆盖/版本冲突（阻断）；E3 索引不及时（可显示滞后、等待补偿）；E4 UI 美观/可用性（排期改进）。
