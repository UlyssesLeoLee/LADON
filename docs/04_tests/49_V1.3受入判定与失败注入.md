# 49. V1.3 受入测试 / 故障注入 / 安全审查

| 验证项 | 操作 | 不可接受结果 |
|---|---|---|
| 本地启动独立 | 禁用网卡、退出 Vercel | 文件列表空白 / 无法打开本地文档 |
| 云档完整性 | 上传后删本地缓存，按版本恢复 | SHA 不匹配仍显示恢复成功 |
| Drive appData | 尝试把个人应用数据共享给组织成员 | 错误宣称可共享 |
| 低空间 | 打满指定缓存配额 | 悄悄清除未备份日志 |
| 同基线并发写 | 两设备分别编辑同文件 | 后提交者覆盖前提交者 |
| 敏感过滤 | 标记私有文件并生成事件、摘要、聊天附件 | 任何敏感详情出现在云端 |
| 认证越权 | 使用其他租户 workspaceId 读取 | 返回数据而不是 403 |
| UI 自适应 | 侧栏折叠、窗口缩放、Hover、键盘 | 残留大块空白 / 仅鼠标可操作 |
| 底部状态 | 发送 AI/成员消息、闲置等待 | 聊天不在最底；关键警告消失 |
| 涌现建议 | 仅触发单种事件 | 自动生成并执行文件修改 |

真实云盘联调必须以独立测试账号及专用空间进行，不允许对用户已有真实文档做清理测试。
