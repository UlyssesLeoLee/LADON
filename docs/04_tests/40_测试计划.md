## 5. 测试数据与隐私
测试仅用临时目录内的虚拟 `.env`/密钥；真实授权 Token 不放源码/日志。每次测试创建新工作区；清理仅删自身临时目录。可恢复性测试须有第二份副本，故障注入不得破坏用户真实数据。Google Drive 登录的自动化测试通过本地回环地址与模拟令牌端点完成，不访问真实 Google 账户，也不发出 Drive 请求；唯一例外为 tc808（`tests/it_google_oauth.rs`）：它调用 `login`，令牌交换请求发送至真实令牌端点 `https://oauth2.googleapis.com/token`，授权码为伪造值 `test-code`，客户端 ID 为 `id.apps` 且不带客户端密钥；HTTPS 证书由系统证书库验证（reqwest 使用 `rustls-tls-native-roots` 特性）；未以真实账户完成；请求以伪造授权码发出，测试核对回调回复以 `HTTP/1.1 200 OK` 开头且含固定 HTML 页面（`<!doctype html>`），失败文本以 `token exchange failed` 开头（网络不可达时同样满足该前缀）且不含授权码与 state 值，测试不调用 Drive；令牌交换失败时不生成也不保存 refresh token。Windows 上 refresh token 只以 DPAPI 密文保存，非 Windows 平台拒绝保存。修改环境变量的测试以锁串行化：`tests/it_google_oauth.rs`（`ENV_LOCK`）与 `ui-prototype/tests/it_archive_nas.rs`（`SERIAL`）。`tests/it_engine_archive.rs`、`tests/it_policy_global.rs` 与 `ui-prototype/tests/it_settings.rs` 各只含一个修改环境变量的测试，无需锁；`tests/it_engine.rs` 中的 `tc_moved_file_keeps_sensitivity_after_rule` 设置 `LADON_ARCHIVE_KEY_HEX` 且不恢复、未加锁，同一二进制中的 `tc314` 在读取该变量之前返回，不受其影响；`tests/it_tagging.rs` 以 `Once` 一次性设置 `NO_PROXY`；`tc217_loopback_endpoint_ignores_http_proxy` 在 `ProxyEnvGuard` 内清除代理相关环境变量并设置 `HTTP_PROXY`（指向 `127.0.0.1:9`），结束时恢复原值，未加锁。回环端点的客户端显式禁用代理（`src/tagging.rs`），因此该变量不影响其他用例的回环请求。真实 Google 账户只用于 `43_ST详细设计.md` 的实机检查，令牌不写入源码、日志或测试记录。
