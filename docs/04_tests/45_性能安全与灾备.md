# 45. 非功能测试说明（性能、安全、可靠性）

## 性能测定
真冷启动：重启 GUI 进程并确保不复用常驻图形/缓存，测 `process_start`, `first_frame`, `first_interaction`；采样 n≥30，计算 p50/p95/p99，并逐磁盘类型（本机 NVMe、外接 HDD）标注。目标≤150ms 是设计验收门槛，未实测。

文件规模：1000、10000、100000、1000000；文本大小：1KB、1MB、50MB、1GB；并发工作：1、4、16 FileSpace；网络状态：在线、离线、慢速/高延迟、429 速率限制。观察内存峰值、I/O、UI 输入延迟、CPU、Token 消耗和本地 CAS 体积增长。

## 安全测试
Path Traversal、Symlink/Reparse、大小写绕过、恶意忽略规则、敏感历史与元数据泄露、伪造 Provider Locator、改写历史对象、AEAD 密文篡改、Token 日志曝光、Agent 越权调用、恶意 prompt injection、WASM 宿主越权。

## 故障恢复
模拟 DB 强制退出、CAS 磁盘占满、归档上传后断电、下载 Hash 不符、Google token 过期、NAS 卸载、Git worktree dirty、Turso index 与 CAS 不一致。恢复须先在隔离目录成功完整演练，再在用户工作区执行。

## 跨平台约束
Windows 11 Pro 为主要验收系统；Linux/macOS 应有兼容测试但不能以 Windows 成绩替代。NTFS File ID/USN 是条件优化，外接盘不一定支持这些能力，必须回退扫描/Hash，不能丢功能。
