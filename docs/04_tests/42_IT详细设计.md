## 数据准备与撤销
`cargo test --test it_history --test it_nema_task` 对已写的 6 条 IT 运行；模块级集成测试用 `cargo test --test it_store --test it_tagging --test it_engine --test it_engine_archive --test it_agent_folder --test it_policy --test it_policy_global` 运行。`it_engine_archive` 与 `it_policy_global` 各只含一个测试并独占测试进程，因为它们设置进程级环境变量（`LADON_ARCHIVE_KEY_HEX`、`LADON_GLOBAL_IGNORE`）；其余测试假定这两个变量未设置。真实 Google Drive、NAS 和断网演练必须使用隔离测试账户及测试目录。恢复与删除测试仅用于独立临时数据，不得针对真实开发项目。`ui-prototype/tests/it_slice_a.rs` 在 `ui-prototype` 目录内以 `cargo test --no-default-features --features kernel --test it_slice_a` 运行。`it_624_root_candidate_links_refused`、`it_638_links_listed_not_followed` 与 `it_641_kernel_failures_report_messages` 仅在 Windows 下编译。`it_624_root_candidate_links_refused` 通过 `cmd /C mklink` 创建文件符号链接，需要 SeCreateSymbolicLinkPrivilege（开发者模式或提升权限的 shell）；缺少该权限时 `mklink` 失败，该用例失败。该用例中的目录联接通过 `mklink /J` 创建，不需要该权限。`it_638_links_listed_not_followed` 通过 `cmd /C mklink /J` 创建目录联接，不需要该权限。

## 否定用例
密码无效→归档拒绝；规则匹配→不得出网；文件改变→恢复计划失效；云端返回错误→本地 CAS 不删；DAG 有环→不执行；Turso 事务失败→不得产生半个版本；远端归档对象认证失败→本地 CAS 不驱逐；内容哈希与敏感文件相同→拒绝归档；`.LADONignore` 语法错误→策略加载失败。
