## 数据准备与撤销
`cargo test --test it_history --test it_nema_task` 对已写的 6 条 IT 运行；模块级集成测试用 `cargo test --test it_store --test it_tagging --test it_engine --test it_engine_archive --test it_agent_folder --test it_policy --test it_policy_global --test it_policy_pending --test it_google_oauth` 运行。`it_engine_archive` 与 `it_policy_global` 各只含一个测试，它们设置进程级环境变量（`LADON_ARCHIVE_KEY_HEX`、`LADON_GLOBAL_IGNORE`）。`tests/it_engine.rs` 中的 `tc_moved_file_keeps_sensitivity_after_rule` 也设置 `LADON_ARCHIVE_KEY_HEX`，该用例不恢复此变量且未加锁；同一二进制中的 `tc314` 在读取归档密钥之前返回，不依赖该变量的状态。`it_google_oauth` 中设置环境变量的用例（`tc806_client_from_environment`、`tc809_provider_token_source`，以及 Windows 下的 `tc809_stored_sign_in_needs_client_id`）以 `ENV_LOCK` 互斥锁串行。`tests/it_engine.rs` 的 `tc328_scan_continues_after_one_file_fails` 需要 Windows 的 `share_mode(0)` 句柄锁定文件，非 Windows 构建中标为 ignored。`tests/it_agent_folder.rs` 的 `tc410_allow_remote_read_refuses_copy_of_excluded_content` 的目录别名分支需要目录联接（`mklink /J`）；无法创建时该分支跳过，设置环境变量 `LADON_REQUIRE_LINK_TESTS` 时改为失败。真实 Google Drive、NAS 和断网演练必须使用隔离测试账户及测试目录。恢复与删除测试仅用于独立临时数据，不得针对真实开发项目。`ui-prototype/tests/it_settings.rs` 与 `ui-prototype/tests/it_archive_nas.rs` 设置进程级环境变量（`LADON_SETTINGS_DIR`、`LADON_GOOGLE_ACCESS_TOKEN`、`LADON_ARCHIVE_KEY_HEX`）：`it_settings.rs` 只含一个测试并独占进程，`it_archive_nas.rs` 的三个用例以互斥锁 `SERIAL` 串行，`it_662_archive_applies_rule_edited_after_open` 在开始时删除 `LADON_GOOGLE_ACCESS_TOKEN`、结束时删除 `LADON_ARCHIVE_KEY_HEX`；两者在 `ui-prototype` 目录内以 `cargo test --no-default-features --features kernel --test it_settings --test it_archive_nas` 运行。`ui-prototype/tests/it_slice_a.rs` 在 `ui-prototype` 目录内以 `cargo test --no-default-features --features kernel --test it_slice_a` 运行。`ui-prototype/tests/slint_trial.rs` 需要 `gui` feature（默认启用），在 `ui-prototype` 目录内以 `cargo test --test slint_trial` 运行。`it_624_root_candidate_links_refused`、`it_638_links_listed_not_followed`、`it_641_kernel_failures_report_messages`、`it_646_list_drives`、`it_651_listing_omits_hidden_and_system`、`it_653_list_subfolders_refusals`、`it_658_list_drives_capacity` 仅在 Windows 下编译，非 Windows 构建的 `it_slice_a` 为 33 项。`it_624_root_candidate_links_refused` 通过 `cmd /C mklink` 创建文件符号链接，需要 SeCreateSymbolicLinkPrivilege（开发者模式或提升权限的 shell）；缺少该权限时 `mklink` ## 否定用例
密码无效→归档拒绝；规则匹配→不得出网；文件改变→恢复计划失效；云端返回错误→本地 CAS 不删；DAG 有环→不执行；Turso 事务失败→不得产生半个版本；远端归档对象认证失败→本地 CAS 不驱逐；内容哈希与敏感文件相同→拒绝归档；`.LADONignore` 语法错误→策略加载失败；规则排除路径上的副本（内容哈希相同）→归档拒绝（tc_moved，IT-031）；与排除路径上曾出现过的内容相同的副本→判为排除内容（tc319，IT-038）；排除内容的副本→远程读取拒绝（tc410，IT-043）；根规则文件缺失→重载失败、采集与归档拒绝（tc326，IT-039）；GUI 采集在根规则文件缺失时拒绝且不记录（it_663，IT-040）；`LADON_GLOBAL_IGNORE` 指向不存在的文件→加载失败并指明文件名（tc513）；单个文件无法读取→扫描返回错误并列出该路径，其余文件仍被采集（tc328，IT-042）；恢复时目标文件已被改动→拒绝（tc304，IT-044）；恢复时目标文件缺失→重建（tc305，IT-045）；嵌套规则无效→采集失败关闭（tc315）；AI 端点静默→超时（tc213，IT-034）；AI 响应超过 8 MiB→拒绝（tc214，IT-034）；AI 端点返回重定向→不跟随（tc216，IT-034）；回环端点设置代理变量→仍直连（tc217，IT-036）。Google 登录：state 不一致→拒绝且错误文本不含授权码（tc804）；未完成授权或缺少授权码→拒绝（tc804）；登录超时→拒绝（tc807）；令牌交换失败→错误文本以 `token exchange failed` 开头且不含授权码与 state 值（tc808），HTTP 状态形式 `token exchange failed (HTTP <状态码>)` 由 `src/google_oauth.rs` 单元测试 `ut_google_02` 断言，`(network error)` 与 `(invalid response)` 两个类别无任何测试断言；未设置客户端 ID→拒绝（tc806）；无已保存登录且令牌为空白→视为未连接（tc809，IT-033）。GUI 命令：NAS 文件夹为相对路径→拒绝（it_659）；无令牌归档到 Google Drive→拒绝（it_660）；恢复时文件已改变或版本缓存已驱逐→拒绝（it_661，IT-046）；删除内部目录或 junction 目标→拒绝（it_657）；重命名被追踪项→拒绝（it_656）；打开工作区后在根规则文件中加入已捕获的文件，再经 GUI 归档→拒绝（it_662，IT-032）；根规则文件无法解析时经 GUI 归档→拒绝（IT-035，未编写，未执行）。
