# 21. 画面基本設計書 — UI 与用户操作设计

## 1. 用户角色
开发者：原生文件浏览、历史/标签/笔记；要件负责人：条款批注、变更审批；管理员：LADON 策略、Provider、容量；Agent 主管：FileSpace 和任务计划/成本。

## 3. 关键交互要求
- `.LADONignore`：文件夹右键可“一键加入 LADON Ignore”，在设置可通过文件编辑器直接修改规则。命中敏感规则用不可误认的盾牌标识，显示拒绝的是远端传输，不是本地查看。
- 历史：每条时间线项目需展示“本地可恢复/云端可恢复/缺失/敏感本地保留”，版本未捕获禁止虚构。
- 文档即任务：选中章节→右键“添加任务/批注”→系统自动带入批准版本和 anchor →接受 Agent 建议时保存审批事件。
- 删除/回滚：操作前查看 Dry-run、受影响路径、可回滚情况；不可逆时二次确认。
- 多 Agent：会话可分屏；一个 Agent 占用文件编辑锁时其他 Agent 仍可读取不可变快照，但冲突显示显式版本差异。

## 4. 画面性能策略
首帧只绘空壳+当前目录名，不在 UI 线程完成枚举；缩略图、LSP、AI、网络、文件预览惰性加载。滑动时虚拟列表、按需请求页数据，取消过期请求。用户操作始终高于索引任务。

## 5. 异常文案与国际化
必要错误必须给：原因、影响、恢复方式。例如“历史对象已归档到 Google Drive，但当前无法连接；不会清理本地剩余副本”。简中、日语、英文使用统一键与参数，不将技术异常字符串直接显示给普通用户。

## 6. MVP GUI 范围
`ui-prototype/` 只演示原生窗口、后台目录枚举、创建 `.LADONignore`；本页其他画面属于详细设计任务，不能作为已完成功能。
