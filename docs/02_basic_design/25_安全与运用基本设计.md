# 25. セキュリティ・運用基本設計書

## 1. 权限边界
普通用户/管理员/Agent/外部插件的访问最小化。所有向 Google Drive、NAS、网络模型、外部插件、MCP 的用户数据出站前必须执行敏感规则及用户授权，未加载规则或规则解析错误必须 Fail-closed。当前实现：规则解析错误时 `Engine::init` 与 `Engine::open` 返回错误；热加载失败时 `Engine::reload_policy` 将 `policy_valid` 置为假，`Engine::archive_version` 随之拒绝全部外部归档。工作区内不存在 `.LADONignore`，且 `LADON_GLOBAL_IGNORE` 未指向存在的文件时，规则集为空且不报错，该情形未实现 Fail-closed。运行路径中已接入的出站检查为 `Engine::archive_version`（由 `src/main.rs` 调用，经 `LadonPolicy::allow_external`，对传入的任意 `StorageProvider` 生效）与 `tag-folder` 命令的远端 AI 请求（排除文件仅允许 `localhost`、`127.0.0.1`、`::1` 的本地模型）；`AgentApi::allow_remote_read` 与 `cloud_journal::publish_segment` 中的敏感检查目前仅由测试调用，未接入运行路径。源码中尚无外部插件与 MCP 的出站路径。

## 2. 凭据
私钥/Google OAuth Refresh Token/AI Key 不写入 Turso 一般表、源代码、CLI 参数或 `.NEMA` 文档。生产计划采用 Windows Credential Manager / DPAPI 或受支持系统密钥链。本期运行时从环境变量读取 Google 临时访问令牌（`LADON_GOOGLE_ACCESS_TOKEN`）、归档密钥（`LADON_ARCHIVE_KEY_HEX`，64 位十六进制）与 AI 密钥（`LADON_AI_API_KEY`），应避免终端回显与系统共享环境泄露。

## 3. 备份与恢复
历史内容自管理不可变对象；Provider 写完不代表备份可恢复，必须读回校验。DB 是索引与事件热点状态，未来需一致性快照/定期 checkpoint 上传受审计的非敏感部分。敏感数据与对应元数据专用本地备份（或用户明确授权的私有介质）。

## 4. 运行与监控
事件队列长度、待备份对象、历史错误数、最后校验时间、CAS 占比、Agent 并发、UI 延迟应可观测。对云端配额不足、令牌失效、磁盘剩余低、历史对象失联弹出清晰报警。允许手工触发校验和修复，不做偷偷的删除。

## 5. 启动模式
Cold：原生 GUI→文件浏览→后台 Worker 可启动；Warm：常驻进程时重新打开窗口；两种模式分别测量。无后台常驻也必须正确运行。对资源繁忙系统优先保证交互。

## 6. 灾备 RPO/RTO
设计目标：本地未上传日志 RPO=0（本地磁盘仍存活且捕获完成时）；远端 RPO 由同步延迟界定；历史恢复 RTO 由对象大小和网络性能决定，需 ST 实测后定 SLA。不能将断网时尚未捕获的文件事件错误标记为云端已保护。

## 7. 安装与卸载
Windows 安装向导由 `Setup.cmd` 启动（以 `-ExecutionPolicy Bypass` 调用 `Install-LADON.ps1`），按当前用户安装，不需要管理员权限，写入范围限于当前用户（安装目录可在向导中改选，但不请求管理员权限）：安装目录（默认 `%LOCALAPPDATA%\Programs\LADON Explorer`；目录非空且不存在 `install-manifest.json` 时拒绝）、用户 PATH（可选，把安装目录按完整路径精确匹配（忽略大小写与末尾反斜杠）追加到 `HKCU\Environment` 的 `Path`，保持原有 `%变量%` 展开形式，写入后广播环境变更通知）、开始菜单项（可选，位于 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\LADON Explorer`，内含「LADON 命令行」与「卸载 LADON Explorer」两个快捷方式）、HKCU 下「已安装的应用」登记（可选，键名 `LADON Explorer`）和示例工作区（可选，默认 `%USERPROFILE%\LADON-Sandbox`，仅在目录不存在时创建，写入 `requirements.md`、测试用 `secret.pem` 并复制 `QUICKSTART.txt`，自检通过后对其执行 `init`，成功时再执行 `scan`）。安装目录内复制程序、图标、许可证、默认配置、示例规则、说明文件与三个 PowerShell 脚本；安装包缺少 `ladon.exe`、`Uninstall-LADON.ps1`、`LADON-Shell.ps1` 或 `LADON-Common.ps1` 时拒绝安装。每次安装写入 `install-manifest.json`，记录实际创建的内容（安装中途失败时也写入已完成的部分；重复安装时沿用清单中已有的 PATH、示例工作区、快捷方式和登记记录，文件列表记录复制结果）。卸载程序 `Uninstall-LADON.ps1` 只按清单还原：移除「已安装的应用」登记；仅当清单记录由安装程序加入 PATH 时移除该条目；删除清单中的快捷方式，开始菜单文件夹为空时一并删除；删除清单中的文件（含清单本身）；示例工作区仅当清单记录为安装时新建，且用户在对话框中选择「是」或传入 `-RemoveSample` 时才删除。随后卸载程序退出，由延迟执行的隐藏 cmd 删除自身两个脚本，再以不带 `/s` 的 `rmdir` 删除安装目录（仅在目录已空时成功，否则保留）；清单缺失时卸载程序直接退出。示例工作区与各工作区的 `.ladon` 历史数据不自动删除。安装开关为 `-Silent`（无界面）、`-NoPath`、`-NoShortcuts`、`-NoSample`、`-NoRegister`，以及 `-InstallDir`、`-SampleDir`、`-StartMenuRoot`、`-RegistryName`、`-PayloadDir`、`-ScreenshotDir`（仅渲染向导页面截图，不安装）；卸载开关为 `-Silent`（无界面，示例工作区默认保留）、`-RemoveSample`、`-InstallDir`。安装包由 `Build-Package.ps1` 生成，随附 `SHA256SUMS.txt`（脚本不校验该文件），zip 需完整解压后运行 `Setup.cmd`；安装与卸载不访问网络；安装后运行 `ladon --version` 自检，失败即报告安装失败，示例工作区初始化失败只给出提示。
