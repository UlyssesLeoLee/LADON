# 26. LADON Explorer 现代侘寂 UI／通信基本设计（外部設計）

## 1. 适用要件
REQ-001~003、REQ-024、REQ-042、REQ-051~056、REQ-063、REQ-064、REQ-069、REQ-072；NFR-001/014/023/026。

## 2. 设计哲学与响应式形态
- 参照 Windows Explorer，默认仅显示标签页、位置导航、搜索、侧边目录、文件表格、底部一行通信栏。**最底边是聊天输入栏**，不得位于中间或覆盖系统标题栏。
- Modern Wabi-Sabi：现代无衬线、暖白/雾灰/少量苔绿、留白、低纹理、低饱和；**禁止仿古纸纹、山水、古风装饰**。
- 左侧目录可变成仅图标栏，鼠标悬停弹出临时二级菜单；键盘焦点也弹出；点击或切换会话后弹层自动关闭；Esc 收起。
- 文件行只在选中或悬停时显示「复制链接／更多／版本」；批量操作位于选中上下文工具栏。
- 文档任务、历史、AI 标签、账号、NAS 均延迟打开；无强制占据主屏的 Dashboard。
- 正常文件浏览时，不启动 AI、LSP、云端 API 或 Shell COM。

## 4. 底部通信栏严格几何规则
- Windows ClientArea = `[0,W]×[0,H]`。Dock 高度 52–60 DIP，始终由主布局 Bottom Slot 分配；若状态栏保留，状态文字移至 Dock 左端，**Dock 仍是最底层交互区**。
- `chatHistoryVisible=false` 默认；`chatHistoryVisible=true` 时，历史面板自 Dock **向上**扩展，聊天输入仍固定窗口底边。
- 用户可禁用消息历史预览但保留输入；独立会话列表在展开时才加载，避免首屏网络请求。
- 屏幕低高度自动限制历史面板最大高度，文件表不得被完全遮挡；三态：隐藏、悬浮展开、固定展开。
- 文本输入支持 Shift+Enter 换行、Enter 发送可配置；草稿按 tenant/workspace/conversation 独立保存。

## 5. 通信安全
- AI 与团队会话严格区分消息来源；团队成员聊天内容**默认不自动发送至模型**。
- 上传附件须先经过 .LADONignore、身份权限、路径与历史版本检查；敏感附件显示本地受限提示。
- @成员产生通知；@Agent 仅产生任务提案，实际文件写入仍经过 FileSpace 审批。
- 消息关联 `(tenant_id,workspace_id,conversation_id,file_ref,version_id,anchor_section)`。

## 6. 可访问性
- 悬停显示的功能必须能通过 Tab、上下文快捷键及触屏长按触达；focus outline 明确；不得仅以颜色表示状态。
- 支持 100%／125%／150% 及高对比度；中/日/英，避免文本截断；左侧栏收起保持 Tooltip。

## 7. 对应原型
`ui-modern-svg/` 下每个 SVG 都是可编辑静态设计稿，不等于完成 Slint 实现。测试视图参照 `docs/04_tests/47_新增Shell与协作测试用例.md`。
