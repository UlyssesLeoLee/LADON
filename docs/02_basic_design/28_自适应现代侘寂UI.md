# 28. UI 基本設計 — Modern Wabi-Sabi / Progressive Disclosure

## 1. 视觉原则

Windows Explorer 操作习惯优先；暖白 + 冷中性色 + 低饱和松绿，尽量无装饰画、纸纹和“古风”纹样。主要展示文件，避免 AI 工作台挤占默认屏幕。

## 2. 布局算法（由 `src/ui_layout.rs` 保证规则）

- 默认侧栏 236px；折叠为 60px；再次展开返回 236px；更窄窗口允许彻底隐藏。
- 主内容区采用 `flex:1;min-width:0` 或 Slint 水平布局拉伸。**折叠不是留白，而是释放 176px 给文件区**。列宽自适应、溢出省略号、横向信息折叠。
- 侧栏 hover 时出现浮层（overlay），但 `content_width` 不变化；键盘 focus 可同样打开。
- 底部通信栏固定窗口最下沿（不在文件区域中间）；默认约 54px，高度由展开历史状态决定，向上覆盖/推高内容区，不新增第二个底部状态栏。
- 文件行右侧操作：只在 hover/focus/选中显示；常规右键始终提供 Explorer 全套菜单与敏感文件命令。
- 状态信息：普通操作完成提示 2.3s 开始淡出，4s 归零；错误、备份损坏、敏感外传阻断、冲突与历史队列耗尽永久可见直到处理。

## 3. UI 状态表

| 状态 | 主内容区 | ChatDock | 状态信息 | 可见高频动作 |
|---|---|---|---|---|
| Idle | 最大化文件列表 | 一行输入 | 空闲后渐隐 | 新建、排序、搜索 |
| Sidebar Collapsed | 填满侧栏释放宽度 | 一行输入 | 保留 | 图标导航 |
| Hover Navigation | 仅悬浮子菜单 | 一行输入 | 保留 | 子项快捷操作 |
| Chat Expanded | 主内容上方保留 | 历史向上展开 | 与输入同层 | AI/团队会话切换 |
| Sensitive Warning | 当前资源可继续浏览 | 一行输入 | 常显警告 | 加入 `.LADONignore`、定位规则 |
| File History | 右侧按需抽屉 | 一行输入 | 保留 | Diff、恢复、归档 |

## 4. 可访问性

任意 Hover 必须有 focus/Shift+F10/键盘菜单替代；Tab 顺序与内容顺序一致；禁用动画时直接切换；对比度、屏幕阅读器标签和 200% 缩放在 ST 验收。

## 5. 原型

`ui-v13-responsive/interactive-preview.html` 真正支持折叠、浮层、聊天、模拟右键；`ui-v13-responsive/15~20_*.svg` 是六张附加可编辑静态 SVG。旧 14 张 SVG 仍在 `ui-modern-svg/`。
