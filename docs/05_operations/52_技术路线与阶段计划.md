# 52. 实施路线与出口判定

## Phase 0 — 可运行原型
实现本地扫描捕获、Turso、哈希链、CAS、`.LADONignore` 基本匹配、AES、Local/NAS/Drive 归档单次调用、文件任务/注释、.NEMA DAG 子集、测试骨架。**本包提供代码但未完成编译和测试证明。**

## Phase 1 — 强化 P0 为可验收
完成真实 Windows GUI、事件完整性/USN 补偿、FileRef 跨移动、SQLite/Turso 故障恢复、OAuth PKCE/Refresh、长文件续传+队列、多 Agent Commit Coordinator、文档内联编辑/审批、批量标签/安全策略、Worktree 安全池化、ST 性能实测。

## Phase 2 — 知识治理
完整 .NEMA Codec、结构化 AST 增量、Concept Guard Hooks、要件自动关联、Turso 向量索引、BM25F 与 IDE1.0 Grep、全文 OCR、Graph 关系浏览、任务统计。

## Phase 3 — 扩展生态
跨设备、NAS 原生 SMB/WebDAV、OneDrive/S3、WASM 插件、MCP、多模型/分布式 Agent、云端日志分片与可验证迁移、增量索引冷热层。

## 交付出口条件
每阶段必须以 RTM 状态为准：功能代码存在 + UT/IT/ST 通过 + 风险解决 + 用户验收签字。禁止以 GUI 原型、README 承诺或样例脚本替代验收。
