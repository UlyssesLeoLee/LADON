# 52. 实施路线与出口判定

## Phase 0 — 可运行原型
实现本地扫描捕获、Turso、哈希链、CAS、`.LADONignore` 基本匹配、AES、Local/NAS/Drive 归档单次调用、文件任务/注释、.NEMA DAG 子集、测试骨架。**核心库与命令行程序在仓库内以 release 配置编译通过（2026-11-19，退出码 0），根 crate 测试代码可编译并执行。命令行程序已完成 release 构建（轻量优化配置）并通过冒烟实测（冒烟实测不构成 UT/IT/ST 执行记录）。根 crate 在 release 配置下执行 `cargo test --release --no-fail-fast -- --test-threads 2`（Windows 11，gnullvm 工具链，执行日期未记录）：库内单元测试 45 项与 `tests/` 下 9 个集成测试二进制 59 项全部通过，合计 104 项通过、0 项失败。ui-prototype 模型单元测试（`cargo test --lib --no-default-features`，执行日期未记录）18 项通过、0 项失败；集成测试 `ui-prototype/tests/it_slice_a.rs` 26 项通过、0 项失败（执行日期未记录）。ui-prototype 为 GUI 原型，上述结果不构成 Phase 1 真实 Windows GUI 的验收依据。仅在上述根 crate 测试二进制中出现的 UT 与 IT 用例已执行并通过；其余 UT 与 IT 用例、全部 ST 与 UAT 的执行状态为 `Not Run`（需要真实 NAS、Google Drive、真实账户或真实 Windows 壳会话的用例同样为 `Not Run`）。** Windows 按用户安装的安装向导与卸载脚本（`packaging/windows/`，入口 `Setup.cmd`，卸载由安装清单驱动，不是 MSI，不写入系统目录，不注册系统服务）已提供，安装与卸载流程已在隔离目录中用真实构建的 `ladon.exe` 验证，图形向导各页已做界面渲染检查，已生成试用安装包（文件夹与 zip），未在目标 Windows 11 机器上完成用户验收。

## Phase 1 — 强化 P0 为可验收
完成真实 Windows GUI、事件完整性/USN 补偿、FileRef 跨移动、SQLite/Turso 故障恢复、OAuth PKCE/Refresh、长文件续传+队列、多 Agent Commit Coordinator、文档内联编辑/审批、批量标签/安全策略、Worktree 安全池化、ST 性能实测。

## Phase 2 — 知识治理
完整 .NEMA Codec、结构化 AST 增量、Concept Guard Hooks、要件自动关联、Turso 向量索引、BM25F 与 IDE1.0 Grep、全文 OCR、Graph 关系浏览、任务统计。

## Phase 3 — 扩展生态
跨设备、NAS 原生 SMB/WebDAV、OneDrive/S3、WASM 插件、MCP、多模型/分布式 Agent、云端日志分片与可验证迁移、增量索引冷热层。

## 交付出口条件
每阶段必须以 RTM 状态为准：功能代码存在 + UT/IT/ST 通过 + 风险解决 + 用户验收签字。禁止以 GUI 原型、README 承诺或样例脚本替代验收。
