# 56. V1.2 → V1.3 迁移与回滚

1. 备份工作区 `.ladon`、当前 Git 分支、既有数据库和 `.LADONignore`。
2. 新增 `sql/003_drive_rules_control_plane.sql`；在复制的测试库先执行事务迁移并比较 schema。不要改写旧事件哈希链。
3. 引入 `StorageRules.version=1`；旧 V1.2 Drive 对象引用继续保留，先双读，待 V1.3 索引重建后才启用新归档事件协议。
4. 工作区默认个人本地优先；未配置 Drive 就不进行远端上传。
5. UI 侧栏状态与底部状态存为每设备本地首选项，不强制覆盖其他设备。
6. 回滚至 V1.2 时禁用新日志段发布，但保留不可变云对象；通过 V1.3 恢复工具将新归档转成 V1.2 能读取的 CAS 数据。禁止直接删除高版本新事件。
7. 恢复/权限/密钥测试未通过时始终停止迁移，而不是强制继续。
