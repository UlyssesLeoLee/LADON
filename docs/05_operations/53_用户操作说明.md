# 53. 用户使用手册（CLI 内核版）

## 初始化
选择需要管理的项目目录并执行 `ladon --root PATH init`，会生成 `.ladon` 与 `.LADONignore`。原有文件不搬迁；首次执行 `scan` 形成当前版本的历史起点。

## 查询修改历史
每次保存后 `capture` 或启动 `watch`，之后 `history <相对路径>` 可得到所有当前可见历史事件和已记录版本；`verify` 验证事件哈希链；`diff FROM_VERSION_ID TO_VERSION_ID` 对比文本内容（若仅云端可用需恢复对象后再比）。

## 批注和文档即任务
`annotate requirements.md --section H1:REQ-001#1 '检查日本侧工艺'` 与 `task requirements.md --section ... 'Review' --description '...'` 将原版本与新任务关联；完整 UI 原位批注仍待实施。

## 管理敏感文件
编辑 `.LADONignore`，写入 `private/`、`*.pem` 等规则。`ignore-check private/x.md` 返回 `EXCLUDED` 说明外传拒绝，本地文件历史继续被记录。规则不代替 NTFS 权限或 Git ignore，请独立管理系统文件权限。

## 归档/恢复
用 `archive VERSION_ID --provider local --destination PATH` 先把历史对象加密写到专门备份目录，并读回验证；用 `plan` 预览，`restore ... --approve` 恢复。密钥丢失则无法解密远端历史，需单独安全保管。

## 常见问题
“文件未变化”：内容 Hash 不变，没有生成多余版本；“文件当前版本已改变”：先扫描或人工审查，防止覆盖；“Google Drive 未授权”：需要真实 OAuth Access Token；“冷内容缺失”：提供对应 Provider 与密钥；“大文件归档失败”：本版读取上限 128 MiB，后续需要真正流式归档。
