## 实现等级准则
| 等级 | 含义 | 可对外宣称 |
|---|---|---|
| Implemented | 源码和可能的测试函数已提供 | 只能说明已提供源码，不说明运行通过 |
| Partial | 某核心路径有代码，但端到端关键缺口 | 演示/技术验证阶段 |
| Design | 已有要件/设计/API/验收标准，尚无执行体 | 只能说明设计完成 |
| Verified | 有真实平台的执行日志、证据、版本签名、复测记录 | 本包当前没有达到此等级的 Rust/Windows 功能 |
