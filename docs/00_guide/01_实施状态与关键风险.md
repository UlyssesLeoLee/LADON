# 01. 实施范围、完成度与风险基线

## 1.1 阶段声明
本包是**IPA 风格的设计全集 + 可运行意图的 Rust 内核源代码 + 未执行测试脚本**。不是全部 P0/P1/P2 功能已完工的软件产品。为了避免错把设计当实际实现，追踪表逐项区分 Implemented/Partial/Design。

## 1.2 完成范围
- 已实现：本地 Turso CRUD、文件扫描捕获、Sha256、.NEMA/Markdown 结构化片段指纹、版本事件链、CAS、基础归档 Provider、AES 加密、.LADONignore 过滤、基础标签、注释任务与 DAG 分批、基本 CLI、Slint 原型。
- 部分：云端 Provider 需要可用 OAuth token 和账号联调；恢复未覆盖 Windows 下所有替换语义；文件监控未覆盖 USN Journal 溢出恢复；敏感排除未覆盖全未来插件；FileRef 的外部重命名关联仍依赖后续稳定文件 ID。
- 设计：高性能浏览器级 UI、真正 Markdown/Office 内联编辑器、全 .NEMA Codec、Turso 向量索引、同步过滤、Worktree 归档、完整 Agent 调度和事务、OCR、LSP、插件、MCP。

## 1.3 关键高风险项
| ID | 风险 | 影响 | 预防与验证 |
|---|---|---|---|
| RSK-01 | 云端误删造成唯一历史副本丢失 | 极高 | 必须先读回并 Hash 验证才执行 CAS evict；默认多副本策略 |
| RSK-02 | `.LADONignore` 被绕过 | 极高 | 外传路径统一策略判定、Fail-closed、自动扫描既有归档 |
| RSK-03 | Worktree 有未提交/未跟踪改动 | 极高 | 未得到完整快照不得删除 Worktree |
| RSK-04 | 文件监听丢事件或临时保存抖动 | 高 | 周期全量核对、USN/文件 ID、稳定时间窗口 |
| RSK-05 | 敏感元数据通过 Turso 同步泄露 | 极高 | 默认 Local-only、字段级分类和同步拦截设计 |
| RSK-06 | 多 Agent 覆盖写 | 高 | FileSpace 哈希前置条件 + 最终 Commit 协调事务 |
| RSK-07 | Google Drive 访问 token 过期/权限变化 | 高 | OAuth Refresh+退避重试+归档队列；本期仅外部 Token |
| RSK-08 | 长期历史增加检索成本 | 中高 | 事件段、分层目录、按需加载、索引检查点 |
| RSK-09 | 第三方库/接口迭代破坏构建 | 高 | `cargo update` 受控、CI 多平台、依赖审查 |
| RSK-10 | 完整格式解析与 .NEMA 版本差异 | 高 | 上游 Codec 对照与语法一致性测试 |
