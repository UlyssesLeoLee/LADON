# 01. 实施范围、完成度与风险基线

## 1.1 阶段声明
本包是**IPA 风格的设计全集 + 可运行的 Rust 内核源代码 + 接入内核的图形界面原型源代码 + 部分已执行并通过的 Rust 测试（仅标识符出现在已执行二进制中的 UT、IT 用例计为已执行；其余 UT、IT 用例与全部 ST、UAT 用例未执行）**。不是全部 P0/P1/P2 功能已完工的软件产品。为了避免错把设计当实际实现，追踪表逐项区分 Implemented/Partial/Design。

## 1.2 完成范围
- 已实现：本地 Turso CRUD、文件扫描捕获、Sha256、.NEMA/Markdown 结构化片段指纹、版本事件链、CAS、基础归档 Provider、AES 加密、.LADONignore 过滤、基础标签、注释任务与 DAG 分批、基本 CLI（已完成 release 构建，并通过临时工作区冒烟实测）。
- 部分：云端 Provider 需要可用 OAuth token 和账号联调；恢复未覆盖 Windows 下所有替换语义；文件监控未覆盖 USN Journal 溢出恢复；敏感排除未覆盖全未来插件；FileRef 的外部重命名关联仍依赖后续稳定文件 ID；图形界面为 Slint 原型（`ui-prototype/`），通过默认开启的 `kernel` 特性，其命令处理工作线程调用内核 `Engine`，已接入工作区打开与初始化、文件夹列表、捕获、版本历史与版本差异命令；内核 `cargo test --release` 的库单元测试与 9 个集成测试二进制共 104 项全部通过；仅标识符出现在上述二进制中的 UT、IT 用例已执行，其余 UT、IT 用例（含没有测试代码的用例，以及依赖真实 NAS、Google Drive、真实账户或真实 Windows Shell 会话的用例）与全部 ST、UAT 用例仍为 `Not Run`；安装向导与卸载脚本（`packaging/windows/`）已提供：安装与卸载流程已在隔离目录用真实构建的 `ladon.exe` 验证，图形向导各页已做界面渲染检查，已生成试用安装包（文件夹与 zip），未在目标 Windows 11 机器上完成用户验收。
- 设计：高性能浏览器级 UI、真正 Markdown/Office 内联编辑器、全 .NEMA Codec、Turso 向量索引、同步过滤、Worktree 归档、完整 Agent 调度和事务、OCR、LSP、插件、MCP。

## 1.3 关键高风险项
| ID | 风险 | 影响 | 预防与验证 |
|---|---|---|---|
| RSK-01 | 云端误删造成唯一历史副本丢失 | 极高 | 必须先读回并 Hash 验证才执行 CAS evict；默认多副本策略 |
| RSK-02 | `.LADONignore` 被绕过 | 极高 | 外传路径统一策略判定、Fail-closed、自动扫描既有归档；敏感排除未覆盖全未来插件 |
| RSK-03 | Worktree 有未提交/未跟踪改动 | 极高 | 未得到完整快照不得删除 Worktree |
| RSK-04 | 文件监听丢事件或临时保存抖动 | 高 | 周期全量核对、USN/文件 ID、稳定时间窗口；USN Journal 溢出恢复未覆盖，FileRef 外部重命名关联依赖后续稳定文件 ID |
| RSK-05 | 敏感元数据通过 Turso 同步泄露 | 极高 | 默认 Local-only、字段级分类和同步拦截设计 |
| RSK-06 | 多 Agent 覆盖写 | 高 | FileSpace 哈希前置条件 + 最终 Commit 协调事务 |
| RSK-07 | Google Drive 访问 token 过期/权限变化 | 高 | OAuth Refresh+退避重试+归档队列；本期仅外部 Token |
| RSK-08 | 长期历史增加检索成本 | 中高 | 事件段、分层目录、按需加载、索引检查点 |
| RSK-09 | 第三方库/接口迭代破坏构建 | 高 | `cargo update` 受控、CI 多平台、依赖审查；`turso` 固定为 `=0.8.3` 并关闭 `fts` 特性（稳定版工具链无法编译该特性）；`Cargo.toml` 的 `rust-version = "1.85"` 与依赖 `notify-types 2.3.1` 要求的 1.91 尚未统一 |
| RSK-10 | 完整格式解析与 .NEMA 版本差异 | 高 | 上游 Codec 对照与语法一致性测试 |
| RSK-11 | Windows 扩展长度路径（`\\?\`）与普通形式路径比较不一致 | 中 | `LadonPolicy::excluded` 要求绝对路径位于规范化根之下；`ladon ignore-check` 需传相对路径或规范化后的绝对路径，`sensitive-add` 与 `shell-menu` 在内部先规范化；`tests/it_policy.rs` 与 UT-010、UT-011 以规范化根构造路径；UT-012（`ut_policy_03_outside_workspace`）使用固定路径 `/this/is/outside`，不以规范化根构造路径 |

## 1.4 验收证据的剩余范围
