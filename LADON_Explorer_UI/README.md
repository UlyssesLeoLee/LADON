# LADON Explorer · Modern Wabi-Sabi · UI state prototypes

设计原则：原生 Explorer 式简洁、无仿古纹理、留白、暖白与苔绿、功能按需显现。

## 场景

- 01_极简默认浏览
- 02_AI聊天展开
- 03_成员聊天展开
- 04_右键扩展操作
- 05_Explorer传统菜单
- 06_文档即任务编辑
- 07_完整版本历史
- 08_AI批量打标签
- 09_账号与租户切换
- 10_Google云盘与NAS
- 11_多Agent并行工作区
- 12_LADON敏感文件排除
- 13_悬停与侧栏折叠
- 14_Agent文件夹API

## 使用

- 在浏览器打开 `index.html` 查看所有 SVG。
- SVG 均为独立可编辑纯矢量文件，尺寸 1600×1000。
- 对应 PNG 仅为预览。
- 默认底部常驻一行 AI / 成员通信栏；聊天记录可以按需展开或隐藏。
- Explorer 右键以 Windows Shell 兼容为实现目标；当前只是 UI 示意。
- 交互、数据库、云同步、租户权限及 Agent 功能均需按正式设计书开发。
