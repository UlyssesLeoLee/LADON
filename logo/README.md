# LADON Explorer logo asset pack

## Production assets

- `logo/LADON_logo_transparent_master_1254.png` — approved-logo artwork on transparent background (1254 × 1254)
- `logo/png/` — 21 PNG sizes: 16, 20, 24, 32, 40, 48, 64, 72, 96, 128, 144, 152, 180, 192, 256, 384, 512, 1024, 1254, 2048, 4096 pixels square
- `platform/windows/LADON_Explorer.ico` — multiresolution icon for Windows Explorer, 16–256 px
- `platform/web/` — favicon ICO, favicon PNG 16 and 32, Apple 180, Android 192/512, Microsoft tile 150
- `previews/` — light, dark, checkerboard background appearance examples (these JPGs are not transparent)

All production PNG files and the Windows ICO use transparency. The approved logo art and its black comic outlines are preserved. The outer black background is transparent.

**Important:** This logo began as a 1254-px raster. The 2048 and 4096 versions are upscaled, not true higher-detail or vector assets. Intricate text is less legible at very small sizes; for a professional 16-px app icon, a separate simplified symbol is recommended.
